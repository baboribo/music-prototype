# Adapter (Claude Code → 공유 프로젝트 스킬)

이 파일은 Codex와 공유하는 프로젝트 스킬의 Claude Code용 adapter다. 전체 지침은
[.agents/skills/project-swift-concurrency/SKILL.md](../../../.agents/skills/project-swift-concurrency/SKILL.md)에
있다. 이 스킬이 트리거되면 그 파일, 같은 폴더의 `references/lifetime-and-loading.md`, `LICENSE`를
읽고 그 지침을 그대로 따른다.

내용을 이 파일에 복제하지 않는다. 원본이 갱신되면 이 adapter도 자동으로 최신 내용을 따른다.
